# Complete Python environment for LostIntoSpacE.
#
#   python -m venv apps/api/venv
#   apps/api/venv/Scripts/python -m pip install -r requirements.txt   # Windows
#   apps/api/venv/bin/python     -m pip install -r requirements.txt   # POSIX
#
# Every version below is the one this repository's full suite was verified
# against (1845 passed / 65 skipped) on CPython 3.14.4. The authoritative
# version RANGES live in the two pyproject.toml files; this file pins the exact
# point in those ranges that is known to work, so a fresh clone gets a running
# environment in one command instead of discovering missing packages one
# ImportError at a time.
#
# Two interpreter floors coexist on purpose and are NOT a mistake:
#   - apps/api/pyproject.toml  requires-python >=3.11  (uses datetime.UTC and
#     `isinstance(x, dict | list)`, both 3.10/3.11+ runtime features)
#   - pyproject.toml (root)    requires-python >=3.9   (the P4-owned data/,
#     search/, ai/ and packages/contracts/ trees stay 3.9-clean on purpose)
# The union is what actually runs the whole repo: Python >= 3.11.
